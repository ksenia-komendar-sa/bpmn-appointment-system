# Проект Запись пациента к врачу
 
Сеть медицинских клиник "Вита" хочет разработать приложение для пациентов. 
В приложении планируется реализовать функционал, который позволит пациентам:
- зарегистрироваться в приложении клиники
- самостоятельно найти нужного врача
- выбрать время для записи
- записаться на прием к врачу

## Задачи:
- Проанализировать процесс записи к врачу AS-IS
- Составить BPMN AS-IS
- Составить диаграмму состояний
- Составить BPMN TO-BE

## AS-IS 
В каждом филиале сети медицинских клиник есть электронный календарь с записями пациентов.
Доступ к календарю имеет врач и администратор именно этого филиала. 
Пациент звонит в нужный филиал клиники и администратор записывает его на прием в электронный календарь. 
Администратор может добавить заметки к записи пациента (например, о том что пациент подтвердил запись)
Администратор может удалить запись, если пациент отменил прием.
Врач отмечает в календаре начало осмотра, записывает жалобы пациента, назначенное лечение и ставит отметку об окончании приема.
